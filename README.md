# AI Bee Pollination Agent

An interactive Arabic project guide and browser demo for the AI Bee Pollination Agent.

## Live demo

After GitHub Pages is enabled and the deployment workflow completes, visit:
https://ganat1337.github.io/roodMap-for-Ai-Project/

If GitHub Pages is not enabled yet, open the repository's **Settings → Pages** and choose **GitHub Actions** as the build and deployment source.

## Run locally

Open `index.html` in a browser. The demo is plain HTML, CSS, and JavaScript; no build step or dependencies are required.

The workflow in `.github/workflows/pages.yml` publishes the repository root whenever `main` is updated.
